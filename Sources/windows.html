    Windows 读取 Mac 格式 iPod

    这台 iPod 使用 HFS+（Mac OS 扩展）格式。Windows 原生没有 HFS+ 读写能力，所以需要额外的文件系统驱动，工具才能看到 iPod_Control 并写入曲库。

    正在检查 Windows 驱动和 USB 设备…
    打开官方下载页
    1. 先断开 iPod，关闭 Windows 的“快速启动”。
    2. 点“安装 10 天试用版”，工具会下载 Paragon 官方 trial.msi 并校验 SHA-256。
    3. 重启 Windows，再连接 iPod，回到这里点“重新检测”。
    4. 设备出现在“导入歌曲”页后，就可以正常拖入和删除歌曲。

    如果已经装过 winget/正式版并提示激活，先在“设置 → 应用”里卸载它，再装这里的官方试用版。试用 10 天后需要向 Paragon 购买授权；本工具不修改 iPod 格式，也不会自动格式化设备。
